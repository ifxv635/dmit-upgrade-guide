## DMIT 配置升级是什么意思：先把概念分开

DMIT 语境下的"配置升级"有两层意思，搞混了容易失望。

**第一层：DMIT 主动给老用户免费升配。** 这是 DMIT 比较有口碑的一点——他们会不定期对硬件进行迭代，且已购套餐跟着同步升配，不额外收费。比如洛杉矶机房在 2024 年底做了一次全面硬件升级，宿主机从第二三代 AMD EPYC 换到了第四代 EPYC 9654，同时加大了存储容量和套餐流量。这种升级是 DMIT 推着走的，用户不用操作，某天你会发现机器配置悄悄变好了。当然，DMIT 维护不一定提前发邮件通知，有时候突然"失联"一会儿，就是在给你升级硬件。

**第二层：你觉得现有套餐不够用，主动申请换到更大的套餐。** 这是大多数人搜"DMIT 配置升级"真正想问的。DMIT 支持这种操作，方式是提工单联系客服，按差价补款升配。流程不算复杂，但需要手动操作，不像某些商家后台有一键升级按钮。

说实话，DMIT 的后台功能设计上偏功能性，没有特别花哨的自助升级界面。想升套餐，最直接的路是提工单，说清楚当前套餐和想换的目标套餐，客服会给你算差价。

## DMIT 的升级路径：三种情况怎么处理

### 情况一：流量跑完了，服务还在不在？

这是升级触发最频繁的场景。

先说好消息：DMIT 不会因为流量用完就直接断你服务。LAX Pro 系列、LAX EB 系列、以及全系 T1 套餐，超量后都是自动降速而不是停机。

降速标准大概是这样：

- 入门款（TINY 级别）：降至约 4 Mbps，登录管理后台和排查问题够用
- 中高配套餐（MINI 及以上）：降至 8～10 Mbps 左右，日常轻度任务感觉不明显

意思是，流量跑完了，机器还活着，网站还在，只是速度慢下来。撑到下个账单周期自动重置，对很多场景来说完全够用。

不过要注意流量计费方式。不同系列计算口径不一样：

- **EB 和 Pro 系列**：双向流量都计，上传下载都算进去
- **T1 系列**：单向取最大值，即 MAX(入站, 出站)，相对更划算

这也是为什么有人觉得 EB 系列"流量不够用"——做代理跑科学上网，双向都在跑，实际消耗会是单向流量统计的两倍左右。

### 情况二：需要主动升级到更大套餐

如果流量限速后已经影响业务，或者需要更多 CPU 和内存，就该升套餐了。

流程是这样：

1. 登录 DMIT 后台（Client Area）
2. 提交工单（Support > Submit Ticket）
3. 说明当前套餐、目标套餐，请求升级
4. 客服会计算差价并告知补款方式
5. 补差价后完成升级

工单客服支持中文，一般 6 小时内回复。如果是紧急情况，写清楚对方通常处理比较快。

升套餐比单独买流量包更划算——DMIT 目前没有单独的流量加购选项，直接跨到下一档套餐是性价比更高的路线。

### 情况三：想从低线路系列换到高线路系列（比如 T1 升 Pro）

这个操作难度稍微高一点。不同系列之间的网络架构不同，直接"升配"在技术上相当于换了一款机器。通常的处理方式是：原套餐用到期，新套餐重新下单——数据需要自行迁移。

所以选套餐的时候，线路档位比配置参数更难改。T1 如果用着觉得大陆延迟差想换 Pro，提前规划好比临时操作省事多了。

## 升级前值得知道的几件事

**关于 IP。** DMIT 有免费换 IP 政策，基本规则是每 15 天可以免费换一次，其他情况是 $5 一次。升套餐不会自动保留原来的 IP，如果 IP 对业务很重要，换套餐前需要考虑清楚。

**关于降级。** DMIT 不支持直接降级——想换到更低档次的套餐，需要等当前套餐到期后重新购买。所以最初选套餐的建议是稍微保守一点，确认稳定再往上走，比一开始买高了再想换要省事。

**关于机房迁移。** 同理，DMIT 不支持在不同机房之间直接迁移，需要重新购买新机房的套餐并自行迁移数据。

**关于退款。** 新用户 3 天内没有滥用的情况下可以全额退款；30 天内按剩余价值退款（退回账户余额免手续费，退回原支付方式会扣支付手续费）。如果对某个套餐不确定，可以先月付测试一个账期，确认满意再换年付节省成本。

## 升级建议：根据实际需求对号入座

**如果你是流量跑完了但机器还活着：** 先别急着升级。LAX Pro/EB 和 T1 系列超量后都是降速不停机，撑到账单周期重置就行，只要业务能接受限速后的带宽。

**如果你是觉得配置不够，要更多 CPU 或内存：** 提工单申请升到更高档位，按差价补款。这是常规操作，客服处理比较熟练。

**如果你是想从 T1 升到 Pro（线路档位升级）：** 这相当于换一台机器，需要重新下单，数据自行迁移。选套餐时建议一步到位，线路档位比硬件配置更难事后改变。

**如果你是预算有限想用最少的钱跑起来：** T1 系列年付入门套餐是性价比最高的切入点，洛杉矶/香港/东京都有 $36.9/年 起的选择，流量也给得相对大方，超量后还有 50～100 Mbps 的限速兜底。

用下来的感受：DMIT 在硬件迭代上确实比较厚道，免费给老用户升配这件事在同类 VPS 商家里不常见。主动申请配置升级的流程也没有想象中复杂，核心就是一封工单的事。难的反而是选准初始套餐——线路档位选对了，后面升配无非是钱的问题；线路选错了，想换就麻烦一点。

## FAQ

**Q：DMIT 配置升级会不会丢数据？**

同系列内升到更高档位，一般不会丢数据，但建议升级前自行备份重要内容以防万一。跨系列换套餐（比如 T1 升 Pro）相当于新开一台机器，数据需要手动迁移。

**Q：想升级，但目标套餐显示缺货怎么办？**

缺货在 DMIT 是常态，尤其是性价比高的几款套餐。可以持续关注官网库存，缺货时下单入口会直接不显示或无法购买。另外，提工单询问客服也是一种方式——有时候后台有库存但前台显示不出来。

**Q：配置升级需要重启服务器吗？**

视情况而定。纯套餐档位升级（加流量、加带宽）可能不需要重启；涉及 CPU/内存/硬盘的硬件变更通常需要一次重启生效。具体以客服操作后的说明为准。

**Q：新注册账号可以马上下单吗？**

DMIT 对部分新注册账号有 7 天等待期才能购买，建议提前几天完成注册。如果着急下单，可以提工单询问客服是否可以加速审核。

**Q：年付和月付升级后价格怎么算？**

DMIT 官方政策是：更改计费周期（比如从月付改年付）会按新价格执行；使用了优惠码的情况下，更改计费周期通常会使优惠码失效，需要重新应用。建议在下单前一次性选定账单周期，而不是先月付再改年付。
